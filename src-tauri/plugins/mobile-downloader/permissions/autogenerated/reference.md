## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-check-tools`
- `allow-search-videos`
- `allow-start-download`
- `allow-open-downloads-folder`
- `allow-open-external-url`
- `allow-read-clipboard`
- `allow-control-download`
- `allow-get-download-state`
- `allow-get-download-history`
- `allow-clear-download-history`
- `allow-open-download-item`
- `allow-share-download-item`
- `allow-delete-download-item`
- `allow-get-mobile-settings`
- `allow-request-mobile-permissions`
- `allow-choose-download-directory`
- `allow-choose-cookie-file`
